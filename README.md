# Netflix Data Analysis 📊

## Objective
To analyze Netflix dataset and find trends in content.

## Tools Used
- Python
- Pandas
- Matplotlib

## Questions Solved
1. Movies vs TV Shows count
2. Top producing countries
3. Content growth per year
4. Most common genres

## Insights
- Movies dominate Netflix
- USA produces most content
- Content increased after 2015

## Conclusion
EDA helps understand streaming platform trends.
